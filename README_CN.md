## 🧠 为什么做 Otta？

AI 很强，但现实很复杂：

- Token 消耗不可控，越用越焦虑
- 每次都要写提示词、调模型
- 插件繁杂，流程混乱
- 数据上传云端，隐私不透明
- 对话是一次性的，没有积累

Otta 的目标很简单：

> 让 AI 成为一个可长期依赖的工具，而不是一个成本黑洞。

# ✨ 核心能力

## 💰 少烧钱

### 1️⃣ 结构化输出引擎

- JSON 输出 + 模板渲染
- 避免无效 token 消耗
- 同等质量下成本降低 60–70%

### 2️⃣ Golden Replay（智能回放）

- 重复任务复用历史最佳执行路径
- 成功方案直接重放
- 大幅减少 LLM 调用

### 3️⃣ 成本可视化

- 每日 token 消耗图表
- 搜索 API 用量统计
- 成本透明可控

## 🎯 不折腾

### 每日私享

- 本地读取浏览记录与对话历史
- 分析兴趣变化趋势
- 自动全网搜索
- 生成私人简报
- 一键进入深度对话

> 打开就有内容，不用反复输入。

---

### 邮件简报

- IMAP 自动连接
- 按主题分类
- 一句话总结
- 提取关键待办
- 快速掌握全局

---

### 有记忆的对话

- 对话成为长期上下文
- 兴趣持续累积
- 越用越顺

---

### 自定义应用系统

- 把对话变成可重复执行的应用
- 支持定时运行
- 专注网络搜索与内容生成
- 运行在受限沙箱内

---

## 🛡️ 放心用

安全是第一设计原则。

- 默认本地数据处理
- 文件操作必须确认
- 危险操作直接拒绝
- 全系统零永久删除
- 删除统一移至回收站，可恢复

你不需要担心：

- 误删文件
- 数据外传
- AI 乱执行

# 🚀 快速开始

```bash
git clone https://github.com/your-org/otta.git
cd otta
pip install -r requirements.txt
python app.py
```

在设置中配置 LLM API Key 即可使用。
